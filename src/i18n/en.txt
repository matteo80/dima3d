= Unexported changes
Apri

Apri un file WRL, STEP, JT, STL, HSF o IV (puoi anche trascinarlo sulla finestra)  [Ctrl+O]
= Open a WRL, STEP, JT, STL, HSF or IV file (you can also drag it onto the window)  [Ctrl+O]
File recenti
= Recent files
Progetto
= Project
Apri progetto…
= Open project…
Riapre i modelli di un progetto .dima3d e le sue modifiche
= Reopens the models of a .dima3d project and its changes
Salva progetto
= Save project
Salva progetto con nome…
= Save project as…
Ctrl+Maiusc+S
= Ctrl+Shift+S
Il progetto (.dima3d) ricorda quali modelli sono aperti e le modifiche: posizioni, colori, nomi, pezzi nascosti o eliminati e la vista. La geometria non c'è: all'apertura si rileggono i modelli originali, quindi non vanno spostati o modificati (se mancano, Dima 3D chiede dove sono). La riduzione delle facce non viene salvata.
= The project (.dima3d) remembers which models are open and their changes: positions, colors, names, hidden or deleted parts and the view. It holds no geometry: on opening, the original models are read again, so they must not be moved or modified (if they are missing, Dima 3D asks where they are). Face reduction is not saved.
Progetto: salva e riapri la scena con le modifiche  [Ctrl+S]
= Project: save and reopen the scene with its changes  [Ctrl+S]
Aggiungi
= Add
Aggiunge uno o più file (WRL, STEP, JT, STL, HSF, IV) alla scena aperta, anche trascinandoli sulla finestra
= Adds one or more files (WRL, STEP, JT, STL, HSF, IV) to the open scene, also by dragging them onto the window
Esporta
= Export
Salva solo le parti visibili in un nuovo file WRL, STL, IV o HSF  [Ctrl+E]\nSolo la selezione: Ctrl+Maiusc+E o il tasto destro
= Saves only the visible parts to a new WRL, STL, IV or HSF file  [Ctrl+E]\nSelection only: Ctrl+Shift+E or right-click
Esporta selezionati…    Ctrl+Maiusc+E
= Export selected…    Ctrl+Shift+E
Salva solo le parti visibili degli elementi selezionati, con i gruppi che li contengono
= Saves only the visible parts of the selected items, with the groups that contain them
Seleziona prima uno o più elementi nell'albero o nella vista
= First select one or more items in the tree or in the view
Formato dell'export
= Export format
Formato compatto
= Compact format
Niente rientri e numeri con la precisione che serve (un milionesimo dell'ingombro): il file è meno della metà. Senza, si copia il testo del file originale.
= No indentation, and numbers only as precise as needed (a millionth of the overall size): the file is less than half the size. Without it, the text of the original file is copied.
Scrivi le normali
= Write normals
Con le normali gli spigoli vivi restano quelli del file. Senza, il visualizzatore le ricalcola (creaseAngle 0,5) e il file è circa la metà.
= With normals, the sharp edges stay as in the file. Without them, the viewer recalculates them (creaseAngle 0.5) and the file is about half the size.
STL (scegli .stl nella finestra Salva)
= STL (choose .stl in the Save window)
In formato testo (ASCII)
= As text (ASCII)
Il testo tiene un nome per pezzo ma è circa 5 volte più grande. Il binario è letto da tutti i programmi. In entrambi i casi colori e albero non esistono nel formato STL.
= Text keeps a name for each part but is about 5 times larger. Binary is read by every program. Either way, the STL format has no colors and no tree.
Open Inventor (scegli .iv nella finestra Salva)
= Open Inventor (choose .iv in the Save window)
In formato binario
= As binary
Il binario è circa un terzo del testo e si apre molte volte più in fretta (FreeCAD, Coin3D). Il testo si può leggere e modificare con un editor. Pezzi, nomi e colori restano in entrambi; le normali seguono l'opzione «Scrivi le normali».
= Binary is about a third of the text size and opens many times faster (FreeCAD, Coin3D). Text can be read and edited in an editor. Parts, names and colors are kept in both; normals follow the "Write normals" option.
In metri (non scalare)
= In meters (no scaling)
Di solito l'IV si scrive in millimetri: la stazione v3 all'apertura chiede di scalarlo. Con questa opzione si scrive in metri, come i WRL e gli HSF.
= IV is usually written in millimeters: the v3 station asks to scale it when opening it. With this option it is written in meters, like WRL and HSF.
Unità
= Units
WRL e HSF si scrivono in metri, IV in millimetri (salvo «In metri»), STL in millimetri.
= WRL and HSF are written in meters, IV in millimeters (unless "In meters" is on), STL in millimeters.
HSF (scegli .hsf nella finestra Salva)
= HSF (choose .hsf in the Save window)
Le normali seguono l'opzione «Scrivi le normali». Con le normali i pezzi hanno gli spigoli vivi calcolati qui (vertici sdoppiati sugli spigoli) e il file è più grande. Senza, il visualizzatore le ricalcola sui vertici uniti: il file è più piccolo ma l'ombreggiatura può sfumare sugli spigoli.
= Normals follow the "Write normals" option. With normals, parts get the sharp edges calculated here (vertices split along the edges) and the file is larger. Without them, the viewer recalculates them on merged vertices: the file is smaller but shading may blur across the edges.

= PDF measure\nOpens a PDF layout, calibrates the scale on a known distance and measures Delta X, Delta Y and distance in mm
